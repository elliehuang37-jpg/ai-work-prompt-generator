# AI 工作提示詞生成器

10 類職能、200 項任務的繁體中文工具，包含財務與電商各 20 項實務場景。先選任務，輸入目的與需求，再複製提示詞到 AI 工具。依模板組合，不呼叫外部模型，不需要 API 金鑰。

每張任務卡皆有「帶入範例」按鈕，需求表單也有「帶入此任務範例」。按下即填入目的、需求、對象、兩個專屬問題、資料摘要與限制，並展開補充條件；先供使用者查看與修改，再產生提示詞。帶入範例會替換目前欄位，並使舊提示詞標示待更新。自訂任務另有通用示例。

## 線上使用

[開啟 AI 工作提示詞生成器](https://elliehuang37-jpg.github.io/ai-work-prompt-generator/)

GitHub Pages 使用 `gh-pages` 分支發布 `dist/` 的靜態檔案。不需要登入，也不會傳送表單內容到 AI 或儲存使用者的輸入。

## 本機啟動

在此資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:4180 。

部署用檔案位於 `dist/`。需使用 HTTP 伺服器或靜態託管，以便載入任務 JSON 與 JavaScript 模組。

## PWA 與離線使用

- `dist/manifest.webmanifest` 使用相對路徑及獨立視窗模式，適用 GitHub Pages 子目錄。
- `dist/icons/` 提供 192、512、maskable 512 及 Apple 180 PNG；`make_pwa_icons.py` 可重建原創圖示。
- `dist/sw.js` 首次連線時完整快取任務庫、生成程式、樣式及圖片；下載完成才顯示離線可用。使用者輸入不寫入快取。
- `dist/pwa.js` 提供安裝提示、離線狀態與手動更新；新版不強制清除輸入，按更新前會標明重新載入會清除本頁輸入。
- iPhone 用 Safari 的「分享 → 加入主畫面」；Android 用 Chrome 的安裝按鈕或選單。首次載入完成後可離線生成提示詞；外部 AI 工具仍需連線。
- **每次修改已部署的快取檔案，務必更新 `sw.js` 的 `CACHE_NAME` 版本。** 新增／改名靜態檔或 query 版本時同步更新 `SHELL`。不刪除其他應用程式的快取。
- `node check-pwa.mjs` 檢查路徑、快取完整性、離線載入、快取清理範圍與下載失敗處理。

## 維護

- `dist/catalog.json`：完整任務資料，每項含專屬追問、角色、交付規格與品質要求。
- `build_catalog.py`：由專案內 `data/部門任務清單.md` 與程式中的專屬追問重建任務資料。修改後執行 `python build_catalog.py`，再以 `node check.mjs` 驗證。
- `example_scenarios.py` 與 `department_extensions.py`：200 項虛構操作範例的真源；後者集中財務及電商的部門、專屬問題與範例，再由 `build_catalog.py` 合併寫入 `dist/catalog.json`。
- `dist/engine.js`：提示詞組合與簡報、圖片、分析、訓練、溝通、計畫六類輸出規則。
- `dist/app.js`：搜尋、部門篩選、表單與複製。
- `dist/styles.css`：響應式版面。
- `node check.mjs`：驗證模板數量、專屬交付、資料缺漏、條件更新與輸出類型。

使用者輸入只留在頁面記憶體，重新整理清除。修改需求後舊結果會標示待更新；切換任務保留共通需求並清除專屬答案。本站不直接生成圖片或簡報檔，也不保證外部 AI 的正確性。

## 提示詞品質 v2

依成果而非單一步驟組織提示詞，加入各類任務的原始材料、實際工作方法、假設檢驗及外部驗收。可選填成功標準、可用工具與希望驗證的假設；200 項範例也包含驗收與工具條件。

- `dist/quality.js`：六類輸出、八類職能及重點任務的工作方法與驗收規則。
- [設計依據、改前改後與驗證界線](docs/prompt-quality-v2.md)

外部模型不具備工具或資料時，提示詞要求列出待驗證事項，不宣稱已執行測試。本工具仍無 API 呼叫，不因增加提示詞要求而自動取得外部工具權限。

## 財務與電商 v2.1

- 財務：ROI、損益會報、三表聯動、預算差異、滾動預測、月結、應收應付、銀行調節、庫存成本、折舊、兩平分析及投資試算等 20 項。
- 電商：上架、商品頁、月計畫、大促、定價、ROAS、CAC/LTV、漏斗、回購、補貨、履約、平台對帳、退貨、月報及直播等 20 項。
- `dist/department-rules.js`：新增任務的逐項工作方法、財務試算及電商口徑。ROI 與 ROAS 分開；報表要求勾稽，避免零分母、錯誤期間及重複扣退款。
- [完整任務清單](data/部門任務清單.md) · [新增部門的範例與檢核說明](docs/finance-ecommerce.md)

本工具產生的是要求 AI 試算的提示詞，不是內建會計或試算引擎。實際數字須交給具計算能力的工具核算，正式會報或入帳前依原始資料與公司政策覆核。
