# 提示詞品質升級 v2

更新：2026-10-28

## 參考與轉化

已閱讀使用者指定的 [AI 生活實驗室文章](https://ailifelab.co/blog/felix-rieseberg-prompt-ambition/) 及其引用的 [Felix Rieseberg 原文](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/)。採用的原則是：從要促成的結果定位任務、用實際專業方法處理原始材料、檢查重要假設、用外部證據驗收，並在必要時借用其他領域的方法。

以下欄位與規則是本工具的產品轉化，不是文章作者提供的企業模板，也不表示已證明各模型的輸出效果必然提升。

## 實際變更

1. 160 項任務與自訂任務共用新的品質引擎：成果、原始材料、方法、假設與驗收。
2. 方法依簡報、圖片、分析、訓練、溝通、計畫區分，再補入職能工作方式；22 項任務另有特定操作規則，其餘以各自必要交付對應檢查。
3. 新增三個選填欄位：成功標準、可用工具與驗證方式、待驗證假設；只填原本兩個必填欄位仍可生成。
4. 160 項一鍵範例加入可觀察驗收與可用工具；部分情境加入有實質判斷價值的假設。
5. 不要求模型任意安裝工具、讀取未提供附件、虛構驗證結果或擴張交付範圍。高難度目標以可測試方案與限制處理。

## 改前／改後示例

| 任務 | 原本側重 | 升級後增加 |
| --- | --- | --- |
| 年度策略簡報 | 角色、逐頁大綱、圖表 | 先釐清需要做的決策；核對來源、比較取捨，以目標讀者回述與試講驗證 |
| 專業設計圖片 | 主體、構圖、顏色 | 保留創作方向，核對字句、比例、參考外觀與手機可讀性；未檢查不得宣稱通過 |
| 業績落差分析 | 指標拆解與改善建議 | 回到原始資料，重算分母與差異，檢查競爭解釋並提出驗證方法 |
| 課程大綱 | 單元、時間與練習 | 用學員的真實工作行為反推練習與評量，以作品驗收 |
| 客戶異議處理 | 異議分類與話術 | 用原話驗證價格是否真正問題，核對承諾，用可觀察回覆驗證 |
| 產品需求文件 | 情境、功能、範圍 | 轉成可驗收行為，涵蓋空資料、失敗與權限情境 |

## 驗證界線

執行程式與內容檢查：160 項模板與範例、必要方法與驗收、使用者條件保留、舊欄位相容、自訂任務、不同輸出類型及瀏覽器核心流程。

工具仍為瀏覽器模板生成器，未接入外部模型。本次驗證的是提示詞內容與 APP 功能；沒有進行付費模型端的成品品質對照實驗，不能把規則檢查稱為實際成效保證。
