# 財務與電商任務擴充

新增財務 F01–F20、電商 D01–D20；現行共 10 類、200 項任務。40 個新任務均有兩個專屬問題、交付規格、逐項工作方法與完整一鍵範例，保留雅芳視覺與既有 160 項任務。

## 使用方式

點「財務」或「電商」部門，或搜尋 ROI、財報、月結、ROAS、平台對帳等關鍵字。手機部門列可橫向滑動，也可直接搜尋部門名稱。選任務後點「帶入範例」，查看目的、需求、來源、假設、可用工具與驗收，再產生提示詞。

## 財務範例的口徑

以下均為虛構教材數字，用於檢查範例是否自洽，不是 APP 內建試算結果：

| 任務 | 示範資料與檢核 |
| --- | --- |
| ROI | 增量淨營收 300000、商品變動成本 120000、活動投入 100000，採此例明訂公式所得 ROI 為 80%；投入與變動成本互不重複，不能推論所有營收都由活動造成 |
| 老闆損益會報 | 實績營收 200 萬、成本 110 萬、費用 70 萬，營業利益 20 萬；預算 220－121－65＝34 萬，需解釋的差額為負 14 萬，尚無證據可直接歸因 |
| 銀行調節 | 銀行 105000 減未兌現票據 10000，帳載 100000 減漏記手續費 5000，兩邊均為 95000；實際入帳須有憑證 |
| 折舊 | 原價 120000、殘值 12000、36 個月，直線法每完整月 3000；起算與月度比例依公司政策 |
| 損益兩平 | 固定費 120000、單價 1000、單位變動費 600，兩平量 300 件；預計 400 件時依銷量口徑安全邊際為 25% |
| 電商組合 | 單件九折 900－450－90－80＝280；兩件 1800－900－180－80＝640／單，320／件；未計廣告、退款等其他成本，不可當淨利 |
| 廣告 ROAS | 廣告 50000，歸因營收 200000，已確認退款 20000，扣退款後為 3.6；須再確認歸因、稅運費及成本，不能當 ROI |

## 方法來源與實務限制

NPV 需處理期初投入與期末現金流；非等距日期要另考慮日期函數。參考 Microsoft [NPV](https://support.microsoft.com/en-us/excel/functions/npv-function)、[XNPV](https://support.microsoft.com/en-us/excel/functions/xnpv-function) 說明。

電商核對要求留意訂單／交易識別碼、重複購買事件及退款資料。參考 Google [交易 ID 與去重](https://support.google.com/analytics/answer/12313109) 與 [電商事件及退款](https://developers.google.com/analytics/devguides/collection/ga4/ecommerce) 說明。不同平台定義不同，仍須核對實際平台與公司口徑；APP 不會自行連線商店或讀取帳務。

會計認列、稅別、費率與人事費用政策均由使用者提供，不從示範推成通用規範。資料不足時交付欄位、公式及待補清單；有工具及授權才實際試算，不能假稱已驗算。工具仍產生提示詞，未串接模型做實際會計運算。
